# Teaching Secure Systems

Teaching cryptography works best when students can see the salt spray—small labs that expose the texture of real deployments.

## Structure for a flipped class
- Pre-class: short primers on the core math and protocol goals.
- In-class: teams map attacks on a toy system, then implement mitigations.
- Reflection: each group publishes a short retro documenting what surprised them.

## What students ask most
- *How do you balance security and latency?* By budgeting for cryptography up front instead of bolting it on.
- *Why do proofs matter if we still test?* Because tests catch regressions; proofs set the guardrails for creativity.

> The best moment is when a student realizes a secure system can still be elegant—and even playful.
